## Como executar localmente

1. Instale o Node.js e o TypeScript (`npm install --global typescript`).
2. Abra a pasta no VS Code.
3. Execute `tsc --watch` no terminal para compilar automaticamente.
4. Abra o `index.html` da raiz com a extensão Live Server.
